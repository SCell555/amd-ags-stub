# AMD AGS stub
Stub DLL, so that the target application does not try to communicate with AMD driver.


## Known bad programs
 - Dishonored 2


## How To

> **Note:** You do not need to download or clone this repository. Simply grab the pre-built release file from the right side of this GitHub page.

1). On the right hand side of the screen, click 'V1.1' under the 'Releases' section.

2). Download the 'amd_ags_x64.dll' file by clicking on it in the list.

3). Navigate to your Dishonored 2 file directory by clicking on the settings button (Cog icon) in your Steam library and selecting:
Manage -> Browse Local Files

4). Move the version of 'amd_ags_x64.dll' you downloaded from GitHub into your
Dishonored 2 folder.

5). When prompted, click 'replace files'.

6). Enjoy the game.
